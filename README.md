## ⚙️ Installation & Setup

Clone the repository:

```
git clone https://github.com/YOUR_USERNAME/personal-portfolio.git
```

Go to project folder:

```
cd personal-portfolio
```

Install dependencies:

```
npm install
```

Run the project:

```
npm run dev
```
